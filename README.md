# URLguard

ドメインにキリル文字を含む HTTP / HTTPS のページ移動を止める Chrome 拡張です。Manifest V3 対応。判定は端末内で完結し、外部通信・履歴収集はありません。

## インストール

1. Chrome のアドレスバーで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. `C:\work\URLguard\extension` を選択します。

読み込み直後から有効です。ビルド済みファイルを同梱しているため Node.js は不要です。変更後は拡張一覧で再読み込みしてください。

## 動作

- キリル文字を含むラベルやサブドメイン、`.рф`、それらの Punycode 表記をブロックします。
- 日本語・ハングル・アクセント付きラテン文字などの国際化ドメインは確認後に自動で開きます。
- 通常の ASCII ドメインはそのまま開きます。パスやクエリのキリル文字だけではブロックしません。
- ブロック画面に Unicode / Punycode の両方を表示します。危険な接続先を開くボタンは設けていません。

Chrome は国際化ドメインを Punycode にしてネットワークルールへ渡します。静的 declarativeNetRequest ルールで国際化ドメインへの移動を拡張内ページに振り分け、RFC 3492 で復号して Unicode の Script_Extensions=Cyrillic を確認します。安全な場合のみ、そのタブの完全一致ホストにセッション許可ルールを設定して移動します。ワーカー起動前にも静的ルールで止めます。

## 範囲と注意点

- 対象はトップレベルのページ移動（アドレス入力・リンク・HTTP リダイレクトなど）です。iframe、画像、fetch、WebSocket 等の通信全般を遮断する機能ではありません。
- 拡張の導入前に開いていたページは自動で閉じません。再読み込み以降の移動が対象です。
- 国際化ドメインへの初回移動は確認ページ経由になります。POST の本文は引き継げないため、対象サイトへのフォーム送信が GET に変わる場合があります。
- ユーザー名・パスワード付きの国際化 URL や、判定失敗時は安全側に停止します。
- シークレットモードは拡張の詳細画面で「シークレット モードでの実行を許可する」を有効にした場合のみ対象です。
- Chrome の内部ページ等、拡張機能が制御できないページは対象外です。キリル文字を使わないフィッシングサイトの判別機能ではありません。

## 開発・検証

依存パッケージ不要。Node.js で `npm run build`、`npm test`。manifest の公開鍵は拡張 ID の固定用で、秘密情報ではありません。公開鍵を変えたらルールも再生成してください。

単体テストでは Punycode 復号・文字判定・ホスト限定ルール・資格情報付き URL を検証します。実 Chrome での拡張読み込みと通信遮断は別途確認が必要です。

仕様資料: https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest
